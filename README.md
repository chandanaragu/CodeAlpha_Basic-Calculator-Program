 Basic Calculator Program Using Python

1. Project Overview

The Basic Calculator is a simple calculator application developed using Python. It performs basic arithmetic operations based on the user's input.

The program allows users to perform addition, subtraction, multiplication, and division.

This project is developed as part of an internship program to practice Python programming fundamentals.

 2.Project Objective

The main objectives of this project are:

- To develop a simple calculator using Python.
- To understand basic arithmetic operations.
- To improve logical thinking and problem-solving skills.
- To practice user input and output handling.
- To learn how to create and manage a project using GitHub.

3. Features

- Addition of two numbers.
- Subtraction of two numbers.
- Multiplication of two numbers.
- Division of two numbers.
- User-friendly menu.
- Displays the calculation result.
- Handles division by zero.
- Provides an option to exit the program.

4.Technologies Used

- Programming Language: Python 3

7. How to Run the Project

Step 1: Install Python

Install Python 3 on your computer.

Step 2: Download the Project

Clone or download this GitHub repository.

Step 3: Open the Project Folder

Open the project folder in your code editor or terminal.

Step 4: Run the Program

Execute the following command:

python calculator.py

If needed, use:

python3 calculator.py

8.Algorithm

1. Start the program.
2. Display the calculator menu.
3. Ask the user to select an arithmetic operation.
4. Get two numbers from the user.
5. Perform the selected operation.
6. Check for division by zero when dividing.
7. Display the result.
8. Repeat the process or exit.
9. Stop the program.
